# Frontend Instructions

This directory is a separate Next.js application.

Use:
- TypeScript
- App Router
- React
- Tailwind CSS
- shadcn/ui
- React Query
- React Hook Form
- Zod
- Playwright

The frontend must not contain business-authoritative security logic.

Backend authorization remains mandatory.

Every page must implement:
- loading state
- empty state
- error state
- permission-denied state where applicable
- responsive behavior
- accessible form labels

Do not modify the backend directory during a frontend-only task.

Report API mismatches before changing backend contracts.
